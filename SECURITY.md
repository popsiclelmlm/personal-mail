# 安全策略 / Security Policy

## 报告安全问题

发现本项目的安全问题，请**不要**公开提 issue。请在 GitHub 仓库的 Security 页点「Report a vulnerability」私下提交，写明：

- 受影响的版本或提交
- 问题描述和可能的影响
- 复现步骤（如有）

我们会尽快确认，修复发布后再公开细节，并在说明里致谢（除非你希望匿名）。

本项目只维护 `main` 分支。

## 与上游有关的问题

本项目由 [cloudflare_temp_email](https://github.com/dreamhunter2333/cloudflare_temp_email) 改造而来。改造中发现的、同样影响上游的问题，我们会先私下报告给上游，等上游发布修复后再公开细节。

---

## Reporting a vulnerability

Please do **not** open a public issue. Use "Report a vulnerability" on the repository's Security tab and include the affected version or commit, a description and impact, and reproduction steps if you have them. We will confirm as soon as we can and publish details after a fix is released, with credit unless you prefer to stay anonymous. Only the `main` branch is supported.

Issues we find that also affect upstream [cloudflare_temp_email](https://github.com/dreamhunter2333/cloudflare_temp_email) are reported to upstream privately first, and details are published after upstream releases a fix.
